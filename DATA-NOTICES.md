# Code and dataset notices

The Python bot code uses the MIT license in LICENSE; original copyright is retained. Included geographic/tide/reference data have separate terms recorded in each dataset's metadata and documentation.

- LINZ settlement names/coordinates and Raglan tide tables: attribution and revision are in datasets/places and datasets/tides, with source links.
- Get Ready emergency reference excerpts: official source/attribution in datasets/references.
- OpenStreetMap route evidence and the separately released national routing/street/water databases: OpenStreetMap contributors, ODbL 1.0; https://www.openstreetmap.org/copyright . The prepared release includes MAP-NOTICES.md.
- Routino XML/source: AGPL-3.0-or-later. Native binaries are built from unmodified Routino 3.4.4 source, retained by setup. The data release also includes the matching unmodified source tarball.
- WMM2025 validation fixture: NOAA/NCEI public-domain model test values; coefficient library attribution is documented in docs/magnetic_bearings.md.

- Online weather: Open-Meteo weather data, CC BY 4.0; geocoding uses GeoNames. Provider terms and source links are in docs/weather.md. No weather snapshots are bundled in code/data releases.

Source dates, attribution and limitations remain available through /bot source and the guides; do not infer live conditions from stored data.
