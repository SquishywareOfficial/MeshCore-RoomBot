# MeshCore RoomBot v0.1.0

First standalone release of the Python USB room bot, separate from the MeshCore
Enhanced firmware. A companion LoRa node is not required for the bot.

- Repeatable setup with verified downloads, an isolated environment, preserved
  operator settings/delivery state, and a native router build for Linux/Pi OS.
- Published versioned NZ routing, street and inland-water datasets. The installer
  downloads the pinned archive from the separate NZ data release.
- Offline towns/place/street lookups, national mapped walking distances, compass
  and true bearings, mapped water approaches, and walking-time estimates.
- Optional saved references, Raglan tides, daylight, calculators, noticeboard
  and voluntary check-ins.
- New `/bot weather [LOCATION]` and `/bot forecast [LOCATION]`: Hamilton defaults,
  NZ overrides, compact Open-Meteo results and explicitly labelled outage cache.
- Existing durable USB cursor/outbox, request deduplication, reconnects and
  bounded room replies retained.

Use [the setup guide](https://github.com/SquishywareOfficial/MeshCore-RoomBot/blob/main/docs/setup.md)
and [weather guide](https://github.com/SquishywareOfficial/MeshCore-RoomBot/blob/main/docs/weather.md).
The code ZIP includes datasets/installer/tools/documentation but excludes all
local TODOs, operator configs, credentials, logs and private databases. National
map data remains in the checksum-pinned `nz-data-20261011-v2` release.

Windows basic setup and Linux full NZ setup are tested. The full routing graph
has been validated on the Pi Zero 2 W; Pi USB/phone deployment still requires
the data/OTG adapter and hardware verification. Online alerts/news/quakes/surf
and Wikipedia answers are not included. Tide coverage is limited to the documented
Raglan snapshot. Mapped water has unknown drinking safety/access.
