# MeshCore RoomBot v0.2.0

Adds offline-first nationwide tides and repeatable tide data gathering/setup.

- All 322 official LINZ catalogue sites, including 88 direct-prediction sites
  covering 2026–2029 and 234 secondary sites with explicitly labelled estimates.
- Next high/low lookup, coastal name aliases and `/bot location tides locations`
  search. Missing official time/height parameters remain unavailable.
- Indexed national tide DB with 494,468 events, kept separate from message state.
- Cache-first reads, bounded near-expiry source refresh, persisted retry backoff,
  atomic update overlay and retained coverage during an internet outage.
- Explicit DST ambiguity, Chatham local time, unusual tide-day counts and source
  discrepancies handled without guessing.
- Both installer profiles download a checksum-pinned tide bundle with raw sources
  and provenance. `tools/prepare_tides.py` reproduces the gathering process.

See [tide commands and coverage](https://github.com/SquishywareOfficial/MeshCore-RoomBot/blob/main/docs/tides.md)
and [setup](https://github.com/SquishywareOfficial/MeshCore-RoomBot/blob/main/docs/setup.md).
Existing operator configuration/delivery state are preserved during setup; review
the proposed config when changing installed data versions. No MCU flashing needed.
